What to try

Five things this prototype actually does

  1. 1. Search & filter — Home. Type in the search bar or tap a need chip (Wheelchair, Low Vision...) to see the list re-rank.
  2. 2. Step-free navigation — Routes. Open a place → "Get step-free route" → Start Navigation, and watch the route ribbon react to a live barrier report.
  3. 3. Report a barrier — Report. Submit a real report; it lands in Community as "Pending".
  4. 4. Community verification. Upvote a pending report 3 times and watch it flip to "Verified" — and update the place's badge on Home.
  5. 5. Accessibility settings. Tap the gear icon: adjust text size or flip on High Contrast mode, live.

Stack (matches Stage 1 deck)

React Native (this demo: HTML/Tailwind/JS) Node.js + Express API PostgreSQL + PostGIS Firebase Realtime Google Maps / OSM TensorFlow / OpenCV

All data on this screen is mock/local (stored in memory for this session) — nothing is sent to a server.
